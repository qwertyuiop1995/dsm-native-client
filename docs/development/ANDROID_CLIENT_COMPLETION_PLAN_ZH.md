> 文档状态：活动计划
> 建立日期：2026-08-02
> 适用范围：`android/` 原生工程及其使用的公共契约、兼容矩阵和自动化测试
> 当前完成情况、真实验证和阻塞项仍以[当前开发进度](../progress/STATUS.md)为准；
> 跨平台差异以[平台功能矩阵](../progress/PLATFORM_MATRIX.md)为准。

## 1. 文档用途

本文用于完成三件事：

1. 将 Android 从当前的基础入口和列表实现，逐步补齐到可日常使用的原生 DSM 客户端。
2. 为每一阶段提供稳定编号、依赖、完成定义和进度记录位置，避免换人或换电脑后重新盘点。
3. 固化新电脑上的环境恢复、构建、模拟器/真机调试、验证和安全交接流程。

本文不是 DSM API 事实来源，也不把 macOS 已实现能力自动视为 Android 已验证能力。
源码、契约、ADR、脱敏 Fixture、兼容矩阵和可复现测试结果优先于本文中的历史描述。

## 2. 状态维护规则

### 2.1 状态值

| 状态 | 含义 |
| --- | --- |
| `NOT_STARTED` | 尚未进入实现 |
| `IN_PROGRESS` | 已开始且存在明确未完成项 |
| `IMPLEMENTED` | 源码调用链已建立，尚未满足完整自动化或设备验收 |
| `UNIT_TESTED` | 领域、Repository 或界面状态已有自动化验证 |
| `DEVICE_VERIFIED` | 已在 Android 模拟器或真机验证，但不代表真实 NAS 行为通过 |
| `NAS_VERIFIED` | 已在记录完整版本和权限类别的专用 NAS 环境验证 |
| `BLOCKED` | 缺少契约、权限、设备、测试目标或外部决策 |

阶段不能因为页面可打开就标记为完成。涉及真实 DSM 读写的能力至少需要
`UNIT_TESTED`，发布能力需要对应的 `DEVICE_VERIFIED`，写操作兼容结论还需要
`NAS_VERIFIED`。

进度统计只计算 A0–A8 中没有下级复选框的复选项；这些复选项统一视为可验证的叶子
开发目标。纯真机、OEM、TalkBack、系统文件提供程序和真实网络环境验收统一放入 A9，
不再冒充尚未实现的开发能力，也不因移出 A0–A8 而视为已经通过。带下级复选框的
父项仅标记其同一行所述实现切片，不表示整个子树已经完成，也不重复计分；普通项目符号
中的实现证据、最近记录、第 18 节执行队列和第 16 节换电脑检查不进入开发完成率。
A9 的真机、NAS、签名和发布验收单独报告，不能用开发完成率代替。

经第 89 批最终契约与移动端适配复核，依赖未公开私有写协议、缺少稳定对象身份，或无法在
Android WebView 中满足非持久会话隔离的能力，不再作为当前 Android 开发叶子。它们保留
在各模块的“版本化契约后再评估”记录中，不能标记为已实现，也不能用猜测请求开放入口。

### 2.2 每次开发后的同步位置

每次完成一个可独立验证的切片后，按以下顺序更新：

1. 更新本文第 4 节的阶段状态和第 15 节的最近工作记录。
2. 若实际能力或平台差异变化，同步更新
   [平台功能矩阵](../progress/PLATFORM_MATRIX.md)。
3. 若测试结果、阻塞项或当前事实变化，同步更新
   [当前开发进度](../progress/STATUS.md)。
4. 若优先级、里程碑出口或范围变化，才更新
   [产品路线图](../progress/ROADMAP.md)。
5. 若 API 契约变化，同步评估 Apple、Android、Windows 五端计划与兼容矩阵。

禁止只在聊天、终端历史或本机笔记中记录完成情况。

- 大屏/平板或折叠屏、自由窗口和手动分屏下的 Compact/Medium/Expanded 切换，以及

  只读目标和撤销 URI 授权时的安全失败与恢复提示。
- Doze、后台限制和低电量下任务被延后或停止时不重复提交、不伪造持续运行，并能恢复或
  提示核对；不承诺绕过 Android 后台限制持续传输。

  使用其他应用打开，不显示错误图片或伪造可播放状态。

- 系统目录选择器和一个用户实际使用的照片备份来源；覆盖长期 URI 授权、重启、撤销授权
  及超过 10,000 项时零部分入队并暂停。
- 真实 TalkBack 下的主导航、五个高频模块、管理模块和危险确认流程。
