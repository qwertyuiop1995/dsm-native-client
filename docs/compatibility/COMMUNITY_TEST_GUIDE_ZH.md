# 社区兼容性测试指南

[English](COMMUNITY_TEST_GUIDE_EN.md)

本指南对应 `testSuiteVersion: 2`。测试目标是确认岚仓在指定版本组合中的用户可见行为，不用于发现私有 API，也不要求抓包或读取诊断日志。版本 1 报告仍可保留和校验，但不包含桌面云盘检查。

## 测试前准备

- 确认 NAS 和账号属于你，或你已获得明确授权。
- 记录岚仓版本、客户端平台版本、NAS 产品型号、DSM 完整 Build 和相关套件版本。
- 不要记录序列号、设备名称、地址、QuickConnect ID 或账号。
- 选择一个不会影响他人的普通账号；只有正常使用确实需要管理员权限时才记录 `administrator`。
- 写操作测试应使用一个新建的空目录和可以丢弃的小型测试文件。不要使用真实照片、文档或备份。
- 如果不确定某项操作是否安全，选择 `skipped`。

## 结果值

| 值 | 使用条件 |
| --- | --- |
| `passed` | 按步骤完成，结果与界面提示一致 |
| `failed` | 无法完成或结果错误 |
| `partial` | 只有部分步骤完成，或结果不稳定 |
| `skipped` | 环境不具备条件，或你选择不执行 |
| `not-supported` | 当前环境明确显示不支持该能力 |

`failed` 和 `partial` 还需选择一个固定失败类别：

- `permission-denied`
- `operation-failed`
- `connection-failed`
- `unexpected-result`
- `app-crashed`
- `unknown`

不要粘贴原始错误、日志、路径或截图。

## macOS 桌面云盘测试

以下能力仅适用于 macOS。iPhone、iPad、Android 和 Windows 报告应记为
`not-supported`，不能用普通文件浏览结果代替 Finder 云盘映射结论。开始前请创建
不含真实资料的专用测试目录；添加和移除映射会改变本机 Finder 状态，但不应修改
NAS 文件。

### `desktop-drive.mount`：添加和移除映射

添加专用测试目录映射，确认 Finder 中出现且名称正确；随后移除映射，并确认 Finder
入口消失。不要记录映射名称或本机路径。

### `desktop-drive.browse`：浏览大目录

打开包含至少 1,000 个合成项目的目录，连续滚动并切换子目录。列表应继续响应，
取消或离开目录后不应持续显示加载。10,000 或 100,000 项结果应在报告外另行注明
规模类别，不要提交文件名。

### `desktop-drive.download-resume`：下载中断与继续

打开一个可丢弃的大型测试文件，在下载过程中暂停网络或退出读取，再次打开文件。
下载应从已有进度继续，文件最终内容应与 NAS 上的测试文件一致。不要提交校验值或
文件名。

### `desktop-drive.keep-offline`：离线副本生命周期

对专用测试目录选择保留离线，观察进度后执行取消；重新开始并等待完成，断开网络
确认可读取，再释放本地副本。空间不足时应说明发生了什么以及下一步操作，不能让
其他映射失效。

### `desktop-drive.upgrade-restore`：升级恢复

从上一个公开版本原位安装候选版本，不先移除映射。重新登录后确认映射仍存在、
暂停状态和缓存位置策略保持一致，并能重新浏览。不得用删除后重建映射代替升级
恢复结论。

## 只读与登录测试

### `connection.resolve`：发现并连接 NAS

使用你平时采用的连接方式打开登录页。能够找到目标 NAS，并在提交凭据前正确显示预期连接目标，即可记为通过。报告中只选择连接类别，不填写地址或 QuickConnect ID。

### `authentication.password`：账号密码登录

使用测试账号完成正常登录。不要在报告中填写账号、密码或错误响应。

### `authentication.otp`：两步验证登录

仅当测试账号已经启用两步验证时执行。确认 App 能进入验证码步骤并成功完成登录；否则选择 `skipped`。

### `authentication.restore-session`：重新打开 App 后恢复登录

完成登录后正常关闭并重新打开 App。确认 App 按当前设置恢复会话或引导重新登录，且不会进入错误账号或错误 NAS。

### `files.list-shares`：显示共享文件夹

进入文件功能，确认当前账号有权访问的共享文件夹能够出现。不要记录共享文件夹名称。

### `files.browse`：浏览目录

打开一个已授权目录并返回上一级，确认项目列表和导航正常。不要记录任何真实目录或文件名。

### `files.search`：搜索文件

在专用测试目录中搜索一个测试项目，确认结果可以打开。不要在报告中填写搜索词。

### `files.download`：下载文件

下载一个无敏感内容的小型测试文件，确认下载完成且内容可打开。测试结束后删除客户端本地副本。

## 受控写入测试

以下项目全部可选。只对测试专用项目执行，不得使用生产数据、唯一副本或共享工作目录。

### `files.upload`：上传测试文件

上传一个无敏感内容的小型测试文件，确认 NAS 端能够看到完整项目。

### `files.create-folder`：新建测试文件夹

在测试目录中新建一个空文件夹，确认创建成功且刷新后仍然存在。

### `files.rename`：重命名测试项目

重命名刚创建的测试项目，确认新名称可见且旧名称消失。

### `files.copy-move`：复制或移动测试项目

在两个测试目录之间复制或移动测试项目，确认目标出现；移动时还应确认源项目消失。

### `files.recycle`：将测试项目移入回收站

仅在共享文件夹已启用回收站时，对可丢弃测试项目执行。确认 App 显示删除确认，并且项目从原位置消失。没有回收站时选择 `not-supported` 或 `skipped`，不要执行永久删除。

### `files.restore`：恢复测试项目

仅恢复上一项产生的测试项目，确认它回到预期测试目录。不得恢复或覆盖真实文件。

## 测试后清理

- 确认测试项目不再需要后，通过正常界面清理。
- 不为完成报告而永久清空回收站。
- 删除本地下载副本和临时测试内容。
- 提交前再次确认报告不含账号、主机、路径、文件名、日志或响应。

如果清理失败，不要重复执行危险操作；停止测试并选择相应失败类别。
