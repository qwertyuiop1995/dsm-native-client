# 桌面云盘大目录基准

该基准用于观察十万条目录元数据进入分页缓存时的耗时和内存趋势，不作为
CI 的硬性性能门槛。日常测试会明确跳过，发布候选版本或缓存策略调整后应手动
运行并保留终端输出。

```bash
LANSTASH_RUN_DESKTOP_DRIVE_BENCHMARKS=1 \
  swift test --package-path apple \
  --filter DesktopCloudDrivePerformanceTests
```

基准固定生成 200 页、每页 500 条合成文件元数据，不读取真实 NAS、主机地址、
账号或文件路径。通过条件是分页缓存最终包含 200 页和 100,000 条记录；耗时用于
同一台机器、相同构建配置之间的回归比较。

真实 Finder 体验仍须在发布验收中验证，包括首次打开、连续滚动、搜索、取消枚举、
内存压力恢复和网络中断恢复。合成基准不能代替真实设备结论。
