## 技术栈

| 平台 | 语言 | UI | 网络 | 安全存储 |

| Android | Kotlin | Jetpack Compose | OkHttp | Android Keystore |
| Windows | C# | WinUI 3 | HttpClient | Credential Locker/DPAPI |
