## 证据边界

- 本次通过已登录 Chrome 只读查看 DSM 信息中心和套件中心详情，核实系统与已安装套件版本。
- 本次没有重新抓取或导出网络请求，没有读取 Cookie、SID、SynoToken、DID 或浏览器存储。
- 私有 API 的方法、版本与响应结论继承自仓库现有的 2026-07-23 至 2026-07-27 脱敏发现记录，并在机器索引中引用原文。
- 仅核实组件版本不能提升 API 证据等级；`static`、`observed`、`read-verified` 和 `behavior-verified` 保持原有含义。

## 升级复验触发条件

以下任一版本变化都必须新建环境基线和升级报告：

- DSM version、build 或 Update 改变。
- File Station、存储管理器、Download Station、VMM、Container Manager、Chat Server 或 Synology Photos 版本改变。
- 存储空间分析器开始接入稳定私有 API。
- 同一版本在不同 NAS、权限类别或连接方式下出现不同契约。
