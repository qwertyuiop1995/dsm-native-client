# macOS 桌面云盘发布与升级验收

本文定义桌面云盘发布候选版本的签名、公证、升级和 Finder 实机验收。自动化测试、
合成基准和无签名构建只能作为前置证据，不能替代正式签名包与真实 NAS 验收。

## 发布包流水线

1. 在干净工作区运行全部仓库检查和 Apple 测试。
2. 使用 `apple/Apps/DsmMac/package.sh` 选择 Developer ID Application 证书生成
   App 与 DMG。临时签名包会移除 File Provider 扩展，不能用于云盘验收。
3. 事先使用 `xcrun notarytool store-credentials` 将凭据保存到登录钥匙串；仓库、
   命令行参数和日志中不得出现 Apple 密码、API 私钥或其正文。
4. 设置 `LANSTASH_NOTARY_PROFILE`，运行
   `apple/Apps/DsmMac/notarize.sh <DMG>`，等待公证、装订票据并完成 Gatekeeper、
   权限和扩展校验。
5. 保存发布版本、构建号、源码提交、安装包 SHA-256 和下表的脱敏结论。不得保存
   签名凭据、NAS 地址、账号、映射名称或真实路径。

## 升级兼容矩阵

每个候选版本至少覆盖下列组合。没有实机证据时必须写“未验证”，不能从其他组合
推断通过。

| 维度 | 最低组合 | 需要记录 |
| --- | --- | --- |
| App 安装 | 上一个公开版本原位升级、全新安装 | 映射是否保留、重复域是否出现、卸载后的预期行为 |
| macOS | 14、15、当前最新稳定大版本 | 系统版本类别、Apple 芯片/Intel、Finder 与扩展状态 |
| 缓存位置 | 系统磁盘、macOS 15+ 合格外置卷 | 拔出、重新接入、空间不足与恢复 |
| 连接方式 | 局域网直连、QuickConnect 直连或中继 | 只记录连接类别，不记录地址或 ID |
| 证书 | 公共 CA、自签名或私有 CA | 只记录证书类别和用户确认结果 |
| 目录规模 | 1 千、1 万、10 万合成项目 | 首屏、连续滚动、取消、内存压力和恢复 |
| 文件下载 | 小文件、大文件、中断续传 | 进度、取消、续传起点和最终内容一致性 |
| 离线保留 | 文件、目录、取消、空间不足 | 计划、下载、释放、重启后的状态 |
| 生命周期 | Finder 重启、App 重启、系统重启、睡眠唤醒 | 域是否重复、任务是否泄漏、状态是否恢复 |
| DSM | 当前维护基线及计划支持的其他 build | DSM 完整版本类别、File Station 版本和证据等级 |

升级前后必须确认映射稳定标识、Finder 入口、暂停状态、缓存位置策略和已完成缓存
记录的兼容性。不得通过删除配置或重新创建映射掩盖迁移问题。

## Finder 实机检查

- 添加、打开、暂停、继续和移除映射；移除前确认没有仍在进行的离线任务。
- 在大目录中滚动和切换层级，然后离开页面，确认枚举能够取消。
- 中断大文件下载后再次打开，确认复用稳定暂存文件且最终结果完整。
- 取消保留离线后确认没有继续增长的进度；再次执行可完成并可释放本地副本。
- 制造可恢复的网络中断、登录失效和空间不足，界面应说明发生了什么以及下一步。
- 导出诊断摘要，检查其中没有 NAS 名称、地址、账号、映射标识、路径、文件名或
  日志正文。

## 五端影响

File Provider 桌面云盘只在 macOS 实现。iPhone、iPad、Android 和 Windows 的普通
文件功能及契约不变；社区测试中的 `desktop-drive.*` 在这些平台记录为
`not-supported`。若未来在其他桌面端实现同类系统集成，必须新建平台计划，不能
直接复用本表中的 macOS 通过结论。
