## 升级复验触发条件

以下任一版本变化都必须新建环境基线和升级报告：

- DSM version、build 或 Update 改变。
- File Station、存储管理器、Download Station、VMM、Container Manager、Chat Server 或 Synology Photos 版本改变。
- 存储空间分析器开始接入稳定私有 API。
- 同一版本在不同 NAS、权限类别或连接方式下出现不同契约。
